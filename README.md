# bikashcsingh.github.io

Personal academic website of **Bikash Chandra Singh**, Assistant Professor of Computer Science at California State University, Fresno.

## Publish with GitHub Pages

1. Create a public GitHub repository named exactly `bikashcsingh.github.io`.
2. Upload `index.html` and `styles.css` to the repository root.
3. Commit the files.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. After a few minutes, the site should be available at:

   `https://bikashcsingh.github.io`

The profile image is loaded from your public GitHub avatar:
